# Generated interior backgrounds

Generated with OpenAI ImageGen on 2026-09-01 for this repository. The existing
`mistfall_farm_commercial.png` artwork was supplied as a style and scale reference.
No third-party game artwork was copied.

- `farmhouse_interior_source.png`: farmhouse with bed, kitchen, storage and one exit.
- `barn_interior_source.png`: six stalls, feed troughs, collection chest, automation and one exit.
- `greenhouse_interior_source.png`: twelve reachable beds, water equipment and one exit.

The corresponding `assets/runtime/backgrounds/interiors/*.png` files are exact
640×360 runtime derivatives. The generation prompts required the existing dark,
misty rural-fantasy palette, top-down three-quarter perspective, grounded contact
shadows, no characters, no text, no markers and unobstructed interaction paths.
