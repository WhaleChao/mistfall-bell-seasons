# 發布狀態與後續路線

v1.0.0 商業候選版已完成原規劃的 Windows x64、繁體中文、單人、30 日曆、農場生活、長期社交家庭、三年主線、40 層動作洞窟、本機 AI 製作工具隔離與正式匯出門檻。

## v1.x 維護

- 依玩家問題回報修正平衡、控制器型號與存檔邊界。
- 增加更多逐幀 NPC／動物動作、節慶演出與可選音樂曲目。
- 在獨立分支驗證外部 Dialogue／Quest／GLoot adapter 升級。
- 若取得程式碼簽章憑證，再為 Windows 發行檔簽章。

## 不在 v1 範圍

多人、手機／Web、遊玩時 AI、雲端協作、角色老死、世代繼承、模組市集與 AI 圖片生成仍不屬於首版承諾。
