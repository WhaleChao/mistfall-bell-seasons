# 發布狀態與後續路線

v1.2.1 是建立在 v1.2.0 內容上的 Windows x64／macOS Universal 2 修復發行版：完成繁體中文 30 日曆、長期農場生活、社交家庭、重寫的三年主線、三張新區域、40 層動作洞窟、異潮釣魚／古神首領、9 種農場自動化，以及玩家自行開設的 ENet 多人伺服器，並修正 macOS 啟動、存讀、主線與數項可達性問題。真 alpha 圖集、百年自動化存檔、五種解析度、Steam Big Picture 品質基準、完整 ZIP、授權原文與 7 服 31 客（含 16 人最大容量）都納入門檻。Studio、九格式文件解析與真實 4B／9B 本機 AI 亦通過實機驗收。Steam 尚未上傳；相關檔案只保留作未來相容性檢查。

## v1.x 維護

- 依玩家問題回報修正平衡、控制器型號與存檔邊界。
- 增加更多逐幀 NPC／動物動作、節慶演出與可選音樂曲目。
- 增加自動化物流顯示、更多設備配方與平衡遙測的離線匯出工具。
- 在獨立分支驗證外部 Dialogue／Quest／GLoot adapter 升級。
- 若取得程式碼簽章憑證，再為 Windows 發行檔簽章。
- 若取得 Apple Developer ID，再為 macOS 發行包完成 hardened runtime、notarization 與 stapling；現階段只提供可驗證的 ad-hoc 簽章。
- 若取得實體手把與 Steam Deck，再評估完整控制器支援與 Deck 相容性，不以映射測試代替硬體驗收。

## 不在 v1 範圍

手機／Web、遊玩時 AI、雲端協作、角色老死、世代繼承、模組市集、Steam 上架／媒合／Cloud／Workshop 與 AI 圖片生成仍不屬於目前承諾。
