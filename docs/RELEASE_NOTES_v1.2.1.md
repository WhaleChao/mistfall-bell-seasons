# 《霧落農歌：鐘塔之季》v1.2.1

v1.2.1 是讓玩家可直接下載使用的雙平台修復版。Windows x64 與 macOS Universal 2 由同一個標籤重建，完整攻略亦已放入兩個離線 ZIP。

## 修復重點

- 修正 macOS LaunchServices 啟動路徑、註冊／啟動測試時序與測試資料互撞；最終 ZIP 會重新解壓、驗證簽章，並以直接執行及 LaunchServices 各啟動一次。
- 標題畫面輸入名字時，不再因輸入 `E`／`M` 或中文輸入法組字誤觸開始、互動或多人選單。
- 鍵位存檔遇到無法讀取或損壞內容時會保留預設操作；Command／Option／Shift／Control 組合鍵可在重啟後正確還原。
- 快速讀檔會同步還原地圖、背景、玩家位置、洞窟進度與異潮首領狀態；連線世界停用單人快速存讀，避免和伺服器世界不同步。
- 主線目標達成後可再次與米拉交談完成章節，不再因首次接任務時條件不足而永久卡關；章節獎勵只發放一次。
- 修正鐘窟電梯續闖與最終／無限挑戰恢復、Rank 7 玻璃來源、池塘／河流魚場、放牧產物、動物繁殖、自動化實際循環及四種不同異魚成就。
- 新增完整繁體中文攻略，涵蓋安裝、操作、農作、動物、料理、自動化、釣魚、鐘窟、關係、節慶、三年主線、成就與多人遊戲。

## 相容性與驗證

- SaveGame schema 維持 v5，v1.2.0 存檔可直接沿用，舊 v1～v4 存檔仍可逐版遷移。
- 多人網路協定維持 `1.2.0`；v1.2.0 與 v1.2.1 可相容連線。
- 可視全功能驗收 157/157，保留 20 張實際遊戲畫面；圖片與圖集閘門 794/794。
- 長期壓力涵蓋 12,000 遊戲日、12,000 自動化週期、400 次自動化月存檔與 250 次磁碟存讀。
- macOS 成品包含 `arm64` 與 `x86_64`，最低版本為 Apple Silicon macOS 13、Intel macOS 11。

## 下載安全提示

- macOS App 使用 ad-hoc 簽章，尚未取得 Apple Developer ID 或 notarization。首次被 Gatekeeper 攔下時，請在 Finder 對 App 按右鍵選「打開」，或到「系統設定 → 隱私權與安全性」選「仍要打開」。
- Windows EXE 尚未使用公眾信任的 Authenticode 憑證；請只從本專案 GitHub Releases 下載。
- Release 會附上 `SHA256SUMS.txt`；請核對 ZIP 的 SHA-256 後再執行。
- 單人模式不會建立網路端點；只有玩家主動開設或加入多人世界時才使用 ENet／UDP。
