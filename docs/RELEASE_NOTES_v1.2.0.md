# 《霧落農歌：鐘塔之季》v1.2.0

## 主要更新

- 新增 6×4 農場自動化設計圖與 9 種鐘能設備：發電、抽水、傳輸、播種、灑水、收割、餵食、霧封加工與夢潮凝析均會每日實際運作。
- 三年 12 章主線完整改寫，串起 10 名村民、農場發展、關係、四季鐘窟與異潮釣魚；所有主線仍無日期期限。
- 新增鳴鐘河畔、古鐘林、古鐘機械遺跡三張可進入區域，以及對應採集、釣魚、村民與劇情線索。
- 玩家、角色、動物、敵人與古神圖集重新處理透明背景，清除灰白光暈並保留雞、服裝與高光等亮色內容。
- SaveGame 升級為 v5，保存自動化設備、設定、網路與統計；支援 v1（28 日制）至 v4 逐版遷移。
- 多人協定升至 1.2.0，共享農場會共同操作設備；私人／競爭農場各自保存設備與資源。
- 新增 macOS Universal 2 發行流程，同時支援 Apple Silicon 與 Intel；發行包由 macOS CI 實際簽署、啟動、離線觀測及公開下載重驗。
- 修正 PixelRPG Studio 主畫面根節點零高度，使 15 個製作頁面的版面與滑鼠命中範圍完整填滿 Godot 編輯器。
- 修正 Windows 隨機工作階段 token 以連字號開頭時，真實 AI 驗收參數可能被誤判為命令列選項的問題。

## 已知界線

- 本版本不會上線 Steam；Steam 設定只作未來相容性與宣稱約束。
- 測試機沒有實體手把或 Steam Deck，因此不可宣稱完整控制器支援或 Deck Verified。
- Windows 尚無受信任的 Authenticode；macOS 使用 ad-hoc codesign，尚無 Apple Developer ID 與 notarization。兩平台均提供 SHA-256。
- 多人為玩家自行管理的 ENet／UDP 朋友或 LAN 伺服器，沒有官方帳號、媒合、TLS、NAT 穿透或反作弊服務。
